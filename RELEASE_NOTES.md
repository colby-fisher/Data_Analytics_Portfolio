Release notes — Portfolio upgrade

Summary
This release adds three polished portfolio projects with reproducible ETL, SQL examples, interactive Streamlit apps, exported visuals, unit tests, and CI automation.

Highlights
- NBA rookie shot selection: cleaned pipeline, SQL aggregation examples, Streamlit comparator.
- Churn & Retention: ETL from IBM Telco sample, cohort-style retention visual, revenue-at-risk analytics, Streamlit dashboard.
- Revenue dashboard: transaction ETL, monthly KPIs, anomaly detection, Streamlit dashboard.
- Experiment demo: A/B test analysis, t-test, and approximate power calculator.
- CI: GitHub Actions runs tests on push/PR. 

Notes
- Deploy to Streamlit Cloud by pointing apps to the repo and branch; see DEPLOYMENT.md for steps.
