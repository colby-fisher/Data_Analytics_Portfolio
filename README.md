## What this portfolio demonstrates

- **Data engineering:** reproducible ETL, schema validation, SQLite models, raw-versus-curated data handling, and deterministic outputs.
- **Analytics:** cohort and retention analysis, revenue-at-risk estimation, KPI design, anomaly detection, and experiment evaluation.
- **Communication:** recruiter summaries, technical case studies, documented limitations, stakeholder recommendations, and interactive dashboards.
- **Quality:** automated tests, GitHub Actions CI, accessible charts, and deployment-ready Streamlit apps.
