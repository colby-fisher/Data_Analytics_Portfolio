## Featured project

### NBA Rookie Shot Selection Analysis

**Question:** How did Cooper Flagg, Dylan Harper, and Kon Knueppel differ in shot selection and efficiency during the 2025–26 NBA season?

This project uses NBA shot-location data to compare where each rookie generated attempts, how efficiently each player converted them, and what those patterns may suggest about offensive role and development priorities.

**Skills demonstrated:** Python, pandas, data cleaning, validation, exploratory analysis, KPI development, data visualization, and stakeholder-focused recommendations.
